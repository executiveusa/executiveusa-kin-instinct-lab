# KIN Architecture

## Four layers
1. **KIN Base** — behavior, approval boundaries, privacy, evidence and failure rules.
2. **Deployment Persona** — bounded role behavior.
3. **Human Context** — goals, vocabulary, routines, authorized documents and explicit permissions after assignment.
4. **Private Connections** — connected by the owner; never preloaded into transferable templates.

## Deployment protocol
1. Claim controlled slot.
2. Establish provisioning/recovery ownership.
3. Record agent-native identity separately.
4. Load Base Doctrine.
5. Load one bounded persona.
6. Test permissions and escalation.
7. Perform three real tasks.
8. Capture evidence and failures.
9. Obtain owner confirmation.
10. Mark VERIFIED only when evidence supports it.

## Control-plane views
INVENTORY / AGENTS / TRAINING / OPPORTUNITIES / HANDOFF / PROOF / SAFETY
